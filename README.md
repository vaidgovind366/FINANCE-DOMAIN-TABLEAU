# 📊 FINANCE DOMAIN | LOAN ANALYSIS DASHBOARD

## 📌 Project Overview

The **Finance Domain – Loan Analysis Dashboard** is an interactive Business Intelligence project developed using **Tableau Public**.

The main purpose of this project is to analyze loan applications, funded amounts, received amounts, loan status, loan quality, and overall lending performance.

The dashboard converts raw financial data into meaningful business insights using KPIs, charts, trends, filters, and interactive visualizations.

---

## 🎯 Business Objectives

The main objectives of this project are:

- Analyze total loan applications
- Analyze total funded loan amount
- Analyze total amount received
- Understand Good Loan and Bad Loan performance
- Analyze different loan statuses
- Track monthly loan trends
- Compare MTD and MoM performance
- Analyze loans by purpose
- Analyze loans by grade
- Analyze verification status
- Identify important business insights

## 📊 Key Performance Indicators

The dashboard includes the following KPIs:

| KPI | Description |
|---|---|
| Total Loan Applications | Total number of loan applications |
| MTD Loan Applications | Loan applications received during the current month |
| MoM Loan Applications | Month-over-Month change in loan applications |
| Total Funded Amount | Total amount funded to borrowers |
| MTD Funded Amount | Funded amount during the current month |
| MoM Funded Amount | Month-over-Month change in funded amount |
| Total Amount Received | Total amount received from borrowers |
| MTD Amount Received | Amount received during the current month |
| MoM Amount Received | Month-over-Month change in received amount |
| Average Interest Rate | Average interest rate across loans |
| Average DTI | Average Debt-to-Income ratio |
| Good Loan % | Percentage of good-performing loans |
| Bad Loan % | Percentage of bad-performing loans |

## 📊 Key Business Questions

This project helps answer important business questions such as:

### 1. How many loan applications were received?

The dashboard shows the total number of loan applications and their monthly trends.

### 2. How much money was funded?

The Total Funded Amount KPI shows the total amount provided to borrowers.

### 3. How much money was received?

The Total Amount Received KPI shows the total amount received from borrowers.

### 4. What percentage of loans are Good or Bad?

The dashboard compares Good Loans and Bad Loans to understand overall portfolio quality.

### 5. Which loan purposes are most common?

Loan Purpose analysis helps identify the most popular reasons for taking loans.

### 6. How are loans distributed across grades?

Loan Grade analysis helps understand the distribution of loans across different grades.

### 7. How is loan performance changing over time?

Monthly trend analysis helps identify changes in loan applications, funded amount, and received amount.
